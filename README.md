# Portfolio Terminal

Личный сайт-визитка Никиты Пятова — team lead и engineering manager — в виде
окна терминала. Одна страница с кратким представлением, манифестом, подходом
к работе, контактами и статусом. Команды `whoami`, `cat about.md` и `ls contacts/`
задают структуру страницы и служат оформлением.

Сайт написан на HTML и CSS с небольшим JavaScript для робота и подсветки курсора, без сборки,
пакетного менеджера и backend.
Визуальный стиль Neon Noir сочетает тёмный фон, фиолетовый акцент `#b026ff`
и локальные шрифты с поддержкой кириллицы. Russo One используется для имени,
манифеста, описания и контактных ссылок. JetBrains Mono отделяет команды
и служебные подписи от основного содержания.

Первый уровень внимания — имя и манифест. Ниже идут описание и контакты,
разделённые отступами, без линий и кнопок действий. Ключевые мысли в абзацах выделены
цветом. Команды и статус оформлены как второстепенные подписи, чтобы страница
сохраняла вид последовательного вывода терминала.

## Локальный запуск

Из корня репозитория, при установленном Python 3:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открой [http://127.0.0.1:8000](http://127.0.0.1:8000). Для остановки нажми
`Ctrl+C` в терминале сервера. Установка зависимостей не требуется.

## Структура проекта

```text
.
├── index.html                  # Страница, её тексты, стили и объявления шрифтов
├── system/
│   ├── matrix.css               # Слои и появление подсветки курсора
│   ├── matrix.js                # Canvas: код виден только вокруг курсора
│   ├── robot.css                # Оформление и анимации робота
│   ├── robot.js                 # Перебежки между углами по клику
│   ├── colors_and_type.css      # Токены и типографика дизайн-системы Neon Noir
│   ├── kit.css                  # UI-компоненты; импортирует colors_and_type.css
│   ├── fonts/                   # Локальные WOFF2: Latin и Cyrillic, лицензия Russo One
│   ├── icons/                   # SVG-иконки
│   └── assets/                  # Логомарк и декоративные SVG
├── AGENTS.md                    # Общие инструкции для агентов
├── docs/
│   └── agent-harness.md         # Подключение инструкций к агентной среде
├── tests/
│   ├── matrix.test.cjs          # Подсветка, цикл отрисовки, reduced motion
│   └── robot.test.cjs           # Проверки поведения робота средствами Node.js
└── README.md
```

Основные стили страницы находятся в `<style>` внутри `index.html`.
Стили и поведение робота подключены отдельно из `system/robot.css` и
`system/robot.js`; сам робот нарисован встроенным SVG в `index.html`.
Подсветка курсора использует `system/matrix.css` и `system/matrix.js`.
Файлы `system/colors_and_type.css` и `system/kit.css` сейчас к ней не подключены;
они хранят отдельный набор токенов и компонентов. Шрифты из `system/fonts/`
используются страницей напрямую, SVG-ресурсы пока не используются.

Russo One загружается из двух локальных WOFF2-файлов, суммарно около 12 КБ.
Источник — [Google Fonts](https://github.com/google/fonts/tree/main/ofl/russoone),
лицензия — [SIL OFL 1.1](system/fonts/RussoOne-OFL.txt).
Внешние запросы к сервисам шрифтов при открытии страницы не выполняются.
Основное семейство задаётся через `--font-ui` на `html, body` в `index.html`,
служебное — через `--font-mono` для команд, метаданных и подписей.
Основной текст набран кеглем 16 px с межстрочным интервалом 1.8;
искусственное утолщение шрифта отключено через `font-synthesis: none`.
Inter остаётся ресурсом отдельной дизайн-системы в `system/`,
но текущая страница его не подключает.

## Где менять содержимое

Тексты портфолио и ссылки находятся в [index.html](index.html):

| Что изменить | Где искать |
| --- | --- |
| Заголовок вкладки и описание для поисковиков | `<title>` и `meta[name="description"]` |
| Имя, роль и стаж | Блок `whoami` |
| Манифест | Блок `cat .manifesto` |
| Описание подхода к работе | Два абзаца после `cat about.md` |
| Контакты | Блок `ls contacts/` |
| Статус, квартал и город | Блок `status --now` |
| Цвета, отступы и адаптивность | Встроенный `<style>`, включая `:root` и `@media` |
| Глитч заголовка | `.h > span`, `.glitch-echo` и `@keyframes glitch-*` в `<style>` |
| Внешность и анимации робота | SVG внутри `#terminal-robot` и `system/robot.css` |
| Перебежки и подсказки робота | `system/robot.js` |
| Радиус подсветки, символы и скорость матрицы | `system/matrix.js` |
| Слои подсветки и плавность появления | `system/matrix.css` |

`about.md` и `.manifesto` — подписи внутри страницы, отдельных файлов с такими
именами нет. При изменении роли или позиционирования стоит согласовать видимые
тексты с метаданными в `<head>`.

У заголовка есть короткий CSS-глитч с циклом 9 секунд и небольшим сдвигом
по времени между строками. Первая вспышка начинается примерно через 2,5 секунды.
При изменении заголовка обновляй также `data-text` в соответствующем
`.glitch-echo`, сохраняя пробелы и `&nbsp;`: это декоративная копия для срезов,
скрытая от скринридеров через `aria-hidden="true"`. В режиме
`prefers-reduced-motion: reduce` глитч и мигание каретки отключаются.

Робот появляется в нижнем левом углу, моргает и иногда машет рукой.
Нажатие на него мышью, касанием или клавишами Enter/Space переносит его
к противоположному краю с анимацией бега. Во время перебежки повторные
нажатия игнорируются. При изменении ширины окна он останавливается
в целевом углу. В режиме reduced motion перемещение происходит сразу,
а анимации робота отключены. Без JavaScript робот скрыт.
Его ширина — 64 px, на экранах до 520 px — 56 px. Нижний отступ страницы
оставляет место для робота под последними строками терминала.

При движении мыши в радиусе 220 px проявляется фиолетовый «дождь» из символов.
Радиальная маска плавно скрывает код за пределами света. Эффект лежит поверх
фона терминала, но под текстом, его верхней панелью и роботом; клики проходят
сквозь слой подсветки. Canvas занимает только квадрат 440 × 440 px,
отрисовка ограничена 30 кадрами в секунду и плотностью 2×. При уходе указателя
из окна, потере фокуса или скрытии вкладки отрисовка останавливается.
На устройствах без точного указателя и при касаниях эффект не появляется.
В reduced motion свет следует за мышью, но символы остаются неподвижными.

## Проверки

Линтер и сборка не настроены. Для поведения робота и подсветки есть тесты без зависимостей,
использующие встроенный тестовый раннер Node.js (версия 18 или новее):

```sh
node --check system/robot.js
node --check system/matrix.js
node --test tests/*.test.cjs
```

Тесты проверяют переходы между углами, повторные клики, завершение движения,
работу подсветки и reduced motion. Они не заменяют визуальную проверку
анимаций и Canvas в браузере.

Для документации проверь ссылки и пути, команды запуска и пробелы в diff:

```sh
git diff --check
git diff
git status --short
```

Новые файлы до добавления в Git не попадают в обычный `git diff`; их содержимое
нужно просмотреть отдельно.

После изменения HTML, CSS или ресурсов запусти локальный сервер и проверь:

- Страница открывается, локальные шрифты загружаются; в консоли и Network нет
  новых ошибок относительно исходного состояния.
- На ширине 375 px и 1280 px читаются заголовки, тексты, контакты и статус,
  нет неожиданного горизонтального скролла. При правке адаптивности также
  проверь обе стороны breakpoint 520 px.
- Ссылки доступны через `Tab`, фокус виден, адреса соответствуют тексту.
- Робот бежит в обе стороны по клику и Enter/Space, останавливается у краёв,
  не застревает после изменения ширины окна. Последние строки страницы
  доступны над ним при прокрутке до конца.
- Матрица видна только рядом с курсором, текст остаётся читаемым и выделяется,
  ссылки и робот кликабельны. При уходе мыши из окна подсветка гаснет;
  на сенсорном экране она не мешает прокрутке.
- После изменения анимации проверь режим reduced motion, после изменения
  текста — переносы строк и согласованность метаданных.

## Особенности текущей версии

- Email указан открытым текстом и использует обычную ссылку `mailto:`.
  Для отображения контактов не нужны JavaScript или внешние сервисы;
  открытие ссылки зависит от настроенного почтового приложения пользователя.
- В статусе явно указан `Q2 2026`; автоматического обновления даты нет.
  Стаж и статус — авторские сведения, которые обновляются вручную.
- В комментарии в начале `system/colors_and_type.css` упомянут cyan, но
  фактический основной акцент в токенах и на странице — фиолетовый `#b026ff`.
- Конфигурации деплоя и CI в репозитории нет. Для статической публикации нужны
  `index.html` и каталог `system/` с сохранением относительных путей.

сессии.
